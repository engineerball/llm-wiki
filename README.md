# LLM Wiki

This repository hosts a personal LLM-maintained wiki, designed to act as a persistent and compounding knowledge base. Content is incrementally built and maintained from raw sources, then synced from a local "Secondbrain" directory.

## Purpose
The primary goal of this wiki is to organize notes, research, and information related to Large Language Models (LLMs), AI engineering, and related technical concepts. It leverages LLMs to help structure and interlink markdown pages, creating a comprehensive knowledge graph.

## Maintenance
The wiki content is periodically synced from a local `/Users/tk/Documents/Secondbrain/{raw, wiki}` directory. This ensures that the online wiki reflects the latest updates and research from the user's personal knowledge base.

## Published Wiki
The generated wiki, powered by Quartz, is deployed via GitHub Pages. You can access the live wiki at:

[https://engineerball.github.io/llm-wiki/](https://engineerball.github.io/llm-wiki/)
