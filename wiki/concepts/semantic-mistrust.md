# Semantic Mistrust

A state where the [[semantic-layer]] loses credibility because it inherits and masks quality, governance, and reliability issues from the underlying physical data layer.

## Overview
As described by [[animesh-kumar]], semantic mistrust is the "wolf in sheep's clothing" of the semantic movement. When organizations implement a semantic layer without addressing data quality at the source, they risk:
- Providing consistent but incorrect metrics.
- Creating a gap between business-consumable logic and physical reality.
- Rapidly eroding user confidence in the "single source of truth."

## Prevention
The primary defense against semantic mistrust is the implementation of a [[reliable-semantic-stack]] and the use of **model-first [[data-products]]**, which establish Service Level Objectives (SLOs) and guarded access before data is activated in the semantic layer.
