# Justin Young

Engineer at [[Anthropic]]. Primary author of "Effective harnesses for long-running agents" (2026) on the Anthropic Engineering Blog.

## Contributions

- Authored research on enabling the Claude Agent SDK to work effectively across many context windows
- Developed the [[Initializer-Coding Agent Architecture]] pattern (initializer agent + coding agent)
- Identified four common failure modes in long-running coding agents: one-shotting, premature completion, buggy/undocumented state, premature test passing
