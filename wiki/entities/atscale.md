# AtScale

**AtScale** is an enterprise-grade [[semantic-layer]] platform designed to provide a universal interface for data across various cloud and on-premise sources.

## Key Features

- **Semantic Modeling Language (SML):** An open-source language introduced by AtScale for defining complex semantic models.
- **Universal Semantic Layer:** Provides a consistent metric layer for BI tools like Excel, Power BI, and Tableau, as well as AI/ML applications.
- **Performance Optimization:** Uses autonomous data engineering to optimize query performance across heterogeneous data environments.
