# FinOps Foundation

Vendor-neutral non-profit organization that defines and maintains the FinOps framework — the operating model for cloud financial accountability. Part of the Linux Foundation.

## What They Define

- **Six FinOps Principles** — the core operating model: teams collaborate, decisions driven by business value, everyone takes ownership, data transparency, central team enables, leverage variable cost model
- **FinOps Lifecycle** — the three-phase iterative process: [[finops-lifecycle]] (Inform → Optimize → Operate)
- **FOCUS** — data normalization standard for cloud billing across providers
