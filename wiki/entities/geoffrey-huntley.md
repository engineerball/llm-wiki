# Geoffrey Huntley

Australian software engineer and AI coding practitioner. Creator of the **Ralph Wiggum Technique** — an agentic loop coding methodology for autonomous software development using [[claude|Claude Code]].

## Known For

- **Ralph Wiggum Technique** — autonomous coding loop methodology; demonstrated by building CURSED, an esoteric programming language compiled via LLVM that didn't exist in any LLM training data
- **CURSED programming language** — production-grade esoteric language built entirely by the Ralph technique

## Key Ideas

- **Deliberate intentional practice** — AI outcomes reflect operator skill, not tool quality; "LLMs are mirrors of operator skill"
- **Specifications over prompts** — no "perfect prompt"; build specs through conversation, tune through behavioral observation
- **Eventual consistency** — trust the loop; when things go wrong, tune the environment not blame the tools
- **Monolithic over multi-agent** — deliberately single-process to avoid non-deterministic agent coordination complexity
