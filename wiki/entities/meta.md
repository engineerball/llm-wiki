# Meta

Meta Platforms, Inc. — parent company of Facebook, Instagram, and WhatsApp. Publicly traded (NASDAQ: META). Headquartered in Menlo Park, CA.

## Relevance to This Wiki

### AI Second Brain (2026)

Meta's analytics team built an "AI Second Brain" — a [[harness-engineering|harness]] giving agents persistent, structured access to a knowledge worker's active work. The system reached 63,000+ installs and ~10,000 daily active users across all of Meta's org pillars within 3 months.

Key architectural contributions:
- [[para-method|PARA workspace]] adapted for agent context management
- [[skills-as-markdown|Skills as markdown]] — 3,000+ community-built skills; 9 discipline-specific packages
- [[progressive-disclosure|Progressive disclosure]] as a production-validated context strategy
- MCP server infrastructure for authenticated internal tool access

See [[how-we-built-an-ai-second-brain-for-60k-knowledge-workers-meta]] for the full case study.
