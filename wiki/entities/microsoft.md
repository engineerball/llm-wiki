# Microsoft

Technology company. Relevant to this wiki across semantic layers (Microsoft Fabric) and agentic AI protocols (MCP co-governance, WebMCP proposal).

## Relevant Work in This Wiki

### Semantic Layers

- **Microsoft Fabric** — [[naming-conventions-for-semantic-layers]] — Gold-layer naming conventions for AI Copilot consumption in Fabric: entity-oriented tables, business-friendly naming, AI documentation (descriptions ≤200 chars), linguistic modeling (synonyms + relationships). Defines the target schema for semantic layers consumed by AI agents.

### Agentic Protocols

- **MCP co-governance** — Microsoft is a major adopter of the Model Context Protocol (MCP), which is now Linux Foundation governed. See [[agentic-protocol-stack]].
- **WebMCP** — W3C Community Group proposal (Google + Microsoft); Chrome early preview Feb 2026; pre-standard. See [[agentic-protocols-for-websites-2026]].
