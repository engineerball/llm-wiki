# Snowflake

**Snowflake** is a cloud-based data platform that has increasingly integrated [[semantic-layer]] capabilities to support AI and analytics.

## Semantic Capabilities

- **Semantic Views:** Snowflake provides semantic views that offer AI-powered conversational interfaces.
- **Business Contextualization:** These views help ground AI responses with governed metric definitions and business-contextualized guardrails.
- **Governance:** Leverages Snowflake's core governance and security features to ensure consistent data access.
