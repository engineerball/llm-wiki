# AI Coding Agents & Software Engineering

**Speaker:** Andrew Ng
**Event:** AI Dev 26
**Source:** [YouTube](https://youtu.be/g8um2AEf5ZA)

## Core Thesis

AI coding agents กำลังเปลี่ยนแปลง software engineering อย่างลึกซึ้ง โดยการสร้างโค้ดเร็วขึ้นมากจน bottleneck ย้ายไปอยู่ที่ส่วนอื่น และความต้องการ engineer ยังสูงแต่ skill set ต้องเปลี่ยน

## Key Takeaways

### The Shift in Software Development
- Software creation วันนี้คือการประกอบ building blocks ต่างๆ — AI models, frameworks, APIs, services — เหมือนต่อ LEGO มากกว่าเขียนจากศูนย์
- Coding agents ทำให้กระบวนการนี้เร็วขึ้นอย่างมาก
- ทีม frontier หลายทีมขยับไปสู่ **โค้ดที่ AI สร้างเกือบ 100%** แล้ว

### New Bottlenecks
- เมื่อ coding เร็วแล้ว คอขวดย้ายไปที่:
  - **Product Management** — ต้องกำหนด spec ให้ชัดและรวดเร็ว
  - **Design** — UX/UI ยังคงต้องมีคนทำ
  - **Legal Compliance** — ข้อกำหนดด้านกฎหมายและ regulation
  - **Marketing** — ต้องทำตลาดด้วย
- นี่คือ **ยุคของ Generalist**: คนที่เก่งหลายเรื่อง สลับบทบาทได้ จะมีค่ามากกว่า specialist เพียงคนเดียว

### The "Job Apocalypse" Myth
- Andrew Ng ปิดกั้นความคิดว่า "AI จะมาแย่งงาน engineer ทั้งหมด"
- ความต้องการ engineer ยังสูงอยู่ แต่ **skill set เปลี่ยนแล้ว:**
  - ใช้ AI agents ได้ผล
  - รู้จัก building blocks หลากหลาย
  - เป็น generalist — มองภาพรวม สลับ role ได้
- คนที่ยึดติดกับ "เขียนโค้ดด้วยมือเท่านั้น" ถึงจะมีปัญหา แต่คนที่ยอมปรับตัวจะยังโตต่อเนื่อง
